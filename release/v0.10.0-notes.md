# KenshiProbe v0.10.0

Phase 2 adds a verified original-reference profile and shared-state 0.2 to the
native probe. The corresponding Python source includes a certified-campaign
comparator and a separate opt-in MeitouClient integration. State 0.1 remains
supported; unknown coverage remains `null`, never an invented value.

For each controlled original-game execution, the reference controller applies
and checks `FixRNG=false` and `UseCustomGameSpeeds=false`, along with the four
documented population overrides, records provenance and restores the player's
settings. RE_Kenshi's residual speed callbacks and startup RNG seeding remain
documented deviations; this is not an unmodified vanilla baseline.

The phase 2 quiet-town comparison used **five repetitions per engine** with
canonical state-0.2 captures and verified restoration. The evidence reports
291 stable-divergent metrics, not 291 independent bugs. Sparse snapshots,
loaded-population coverage and five observed repetitions limit interpretation.
Town placement identities and some Meitou fields remain noncomparable.

The phase 2 Python validation recorded **1,975 passed and 25 skipped**. The
Meitou Oracle/camera subset passed 115 cases; its complete suite excluding
`Bench` had 11 failures, reproduced with identical messages on the unchanged
upstream revision. See the [phase 2 validation](../docs/phase2-validation.md)
for exact builds, campaigns and limitations.

This v0.10.0 package is a fresh Release/v100 build of the current probe and
bootstrap, with centralized version metadata and neutral PDB basenames.
The earlier real phase 2 campaigns are identified by their own binary hashes;
they do not constitute a new live loading test of this rebuilt package.
Packaging verifies x64 PE files, reviewed DLL hashes, explicit archive members,
privacy strings, the newly generated zero-record `.mod` descriptor, synthetic
installation and exact restoration. No game was modified by packaging.

Validated phase 2 runtime environment: **Kenshi 1.0.65 Steam, RE_Kenshi 0.3.5,
KenshiLib 0.5.0, Windows x64**. Native builds require Visual C++ 2010 v100;
Python tools require Python 3.11+. Other game/SDK combinations are unverified.

The archive contains two project DLLs, the RE_Kenshi manifest, original empty
mod metadata, installation instructions and GPLv3. It contains no game files,
saved games, SDK binaries, private configuration or decompiled executable code.
The optional preload helper is inert without an explicitly created activation
file. **Raw PDBs are excluded** because they may disclose source-machine paths.
Check `SHA256SUMS` before installing.

The public source documentation and research notes are in English. Historical
measurements retain their original versions and limitations; research material
is separated from the oracle's user documentation.
